The tiles were produced from Protomaps daily builds
(https://protomaps.com), which are built from OpenStreetMap data.

KEEP THIS FILE WITH YOUR MAP
----------------------------
If you downloaded a .pmtiles file on its own, save this text alongside it.
It is the record of where the map data came from and the terms it carries.
If you self-host the map for a Fox Pursuit installation (SETUP.txt Section
2.4), keep this file in the same folder as the .pmtiles.

What this means if you re-host or redistribute this data
--------------------------------------------------------

  uses the map (the Fox Pursuit app shows it automatically on the map;
