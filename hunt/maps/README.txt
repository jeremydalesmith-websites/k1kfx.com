Place your .pmtiles map file in this directory.

By default this package points tileUrl (in 0-config-foxhunt.js) at
maps/springfield-branson.pmtiles, so the map works the instant you publish, even
offline. Ready-made regional maps also stream from https://maps.foxpursuit.com -
set tileUrl to a region's address to use one (SETUP.txt Section 2.1).

To self-host any region (SETUP.txt 2.4), drop its .pmtiles here and keep the
accompanying ATTRIBUTION.txt with it. Use the admin page's "Check map hosting"
button to confirm it loads.
